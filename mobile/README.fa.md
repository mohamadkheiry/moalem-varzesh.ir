# اپ موبایل معلم ورزش

اپ فارسی و راست‌چین فروشگاه با React Native و Expo ساخته شده است. صفحهٔ اول، کاتالوگ، جست‌وجوی فارسی، مرتب‌سازی، دسته‌ها، گالری، گزینه‌های خرید، چاپ سفارشی، علاقه‌مندی‌ها و سبد روی موبایل در دسترس‌اند. رنگ، نشان و فونت وزیرمتن با سایت فروشگاه هماهنگ‌اند.

## اجرای محلی

پیش‌نیازها Node.js 22.13 یا جدیدتر، وردپرس محلی همین مخزن، ووکامرس و قالب فعال معلم ورزش هستند. نشانی فروشگاه را برابر نشانی اصلی ثبت‌شده در وردپرس تنظیم کنید.

~~~powershell
Set-Location mobile
npm ci
$env:EXPO_PUBLIC_STORE_URL = 'http://127.0.0.1:8087'
npm run web -- --localhost --port 8091
~~~

نسخهٔ مرورگری همان کد رابط React Native را اجرا می‌کند. برای اجرای نسخهٔ بومی، زیرساخت Android SDK یا محیط iOS لازم است. دستگاه موبایل باید به نشانی ووکامرس دسترسی داشته باشد. برای شبیه‌ساز یا گوشی Android متصل از طریق ADB، انتقال پورت‌های ۸۰۸۷ و ۸۰۹۱ امکان استفاده از نشانی loopback مطابق وردپرس را فراهم می‌کند. برای استقرار عمومی، نشانی WooCommerce با HTTPS لازم است.

## اتصال به ووکامرس

فهرست، تصاویر، قیمت، گزینه‌ها و وضعیت موجودی با Store API خوانده می‌شوند. تغییرات سبد در ووکامرس انجام می‌شوند. توکن سبد در اپ بومی با Secure Store و در پیش‌نمایش وب در storage همان تب نگهداری می‌شود. علاقه‌مندی‌ها و آخرین کاتالوگ موفق روی دستگاه ذخیره می‌شوند.

ثبت سفارش در تسویه‌حساب ووکامرس ادامه پیدا می‌کند. قالب این مخزن اطلاعات چاپ را همراه سبد منتقل می‌کند و برای مرورگر پیوند مخصوص انتقال سبد از ووکامرس می‌گیرد. مبالغ و روش‌های ارسال و پرداخت را ووکامرس تعیین می‌کند. کد و دادهٔ آزمون فقط از فروشگاه محلی استفاده می‌کنند.

## آزمون

~~~powershell
npm run typecheck
npm test
node --test tests/store-integration.cjs
~~~

آزمون ماتریس از عکس فوری کاتالوگ همین مخزن استفاده می‌کند و دقیقاً ۲۰۰۰ سناریو دارد. ۱۶۵۲ سناریو برای ۸۲۶ گزینهٔ خرید، ۲۳۲ سناریو برای ۱۱۶ کالا، ۷۶ سناریو برای ۱۹ دسته و ۴۰ سناریو برای ورودی‌ها و وضعیت‌های مرزی تعریف شده‌اند.

آزمون رابط مرورگری با Playwright به صورت جداگانه اجرا می‌شود. Playwright باید از بستهٔ ریشهٔ مخزن در دسترس باشد و پیش‌نمایش روی ۸۰۹۱ و وردپرس روی ۸۰۸۷ فعال باشند.

~~~powershell
node tests/browser.cjs
~~~
