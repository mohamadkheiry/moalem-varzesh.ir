# معلم ورزش

فروشگاه فارسی و راست‌چین معلم ورزش روی WordPress و WooCommerce. قالب اختصاصی با PHP، CSS، فونت محلی وزیرمتن و تصاویر واکنش‌گرا پیاده‌سازی شده است. جست‌وجو، گزینه‌های کالا، سبد و تسویه‌حساب از امکانات اصلی ووکامرس استفاده می‌کنند.

## اجرای محلی

نسخهٔ بررسی‌شده از WordPress 7.1.5، WooCommerce 11.3.1، PHP 8.2 و MariaDB 10.4 استفاده می‌کند. فایل‌های هسته، افزونه، پایگاه داده، حساب‌ها، سفارش‌ها و رمزها داخل مخزن قرار نگرفته‌اند.

برای بازسازی، WordPress فارسی و WooCommerce را در یک نصب تازه فعال کنید. پوشهٔ theme را با نام moalem-varzesh داخل wp-content/themes و پوشهٔ plugins/moalem-commerce را داخل wp-content/plugins قرار دهید. در اجرای محلی WP_ENVIRONMENT_TYPE را روی local و DISABLE_WP_CRON را روی true تنظیم کنید. فرمان‌ها از ریشهٔ مخزن و در PowerShell اجرا می‌شوند.

~~~powershell
$wpPath = 'C:\path\to\wordpress'
python scripts/fetch-media.py runtime/media
# ساخت سریع بندانگشتی WebP در صورت نصب Pillow
python scripts/prepare-media.py runtime/media
wp --path=$wpPath plugin activate woocommerce
wp --path=$wpPath plugin activate moalem-commerce
wp --path=$wpPath theme activate moalem-varzesh
wp --path=$wpPath eval-file scripts/setup.php
wp --path=$wpPath eval-file scripts/import-editorial.php
wp --path=$wpPath eval-file scripts/setup-footer.php
wp --path=$wpPath rewrite flush
$env:MV_MEDIA_CACHE = (Resolve-Path runtime/media).Path
wp --path=$wpPath eval-file scripts/import-catalog.php
wp --path=$wpPath eval-file scripts/local-checkout.php
~~~

در XAMPP می‌توان PHP و MariaDB اختصاصی برنامه را پس از نصب با scripts/start-local.ps1 -Runtime C:\path\to\runtime راه انداخت. پوشهٔ Runtime باید حاوی wordpress و mariadb پیکربندی‌شده باشد. آدرس پیش‌فرض http://127.0.0.1:8087/ است.

برای مدیریت فوتر و صفحه‌های راهنما، در پیشخوان به «نمایش ← فوتر و صفحه‌های راهنما» بروید. عنوان‌ گروه‌ها، متن معرفی، رنگ و تصویر را آنجا تغییر دهید. لینک‌های ویرایش، منوهای بومی وردپرس را برای تغییر عنوان و ترتیب پیوندها و ویرایشگر برگه‌ها را برای تغییر متن باز می‌کنند.

## کش و آزمون سرعت در نصب محلی

قالب برای هر جایگاه، اندازهٔ نمایش تصویر را به مرورگر اعلام می‌کند و سبک بلوک‌های وردپرس را هنگام استفاده بارگیری می‌کند. سرور محلی فایل‌های متنی ثابت را با gzip می‌فرستد و فایل‌های نسخه‌دار را در کش مرورگر نگه می‌دارد.

برای فعال‌سازی کش صفحه‌های عمومی، پس از نصب وردپرس این فرمان‌ها را اجرا کنید. صفحات حساب، سبد خرید و تسویه‌حساب و درخواست‌های مرتبط با نشست مشتری از کش صفحه مستثنا هستند.

~~~powershell
wp --path=$wpPath plugin install https://downloads.wordpress.org/plugin/wp-super-cache.latest-stable.zip --activate
wp --path=$wpPath eval-file scripts/configure-page-cache.php
node tests/performance-http.cjs
wp --path=$wpPath eval-file tests/search-visibility.php
~~~

کش محلی از حالت سادهٔ WP Super Cache استفاده می‌کند. آزمون نقشهٔ سایت، فهرست صفحه‌های عمومی را می‌سنجد و تنظیم نمایه‌سازی سایت محلی را دست نمی‌زند. [راهنمای کش ووکامرس](https://developer.woocommerce.com/docs/best-practices/performance/configuring-caching-plugins/) · [راهنمای کش وردپرس](https://wordpress.org/plugins/wp-super-cache/)

برای اندازه‌گیری دوباره با Chrome و Playwright از `node tests/measure-performance.cjs` استفاده کنید. آزمون هر صفحه را سه بار با مرورگر تازه و نمای موبایل باز می‌کند. برای گرم‌کردن کش سرور پیش از اندازه‌گیری، متغیر `MV_WARM_CACHE` را روی `1` بگذارید.

## ساخت تصاویر شفاف کالاها

فرایند برش، فایل اصلی هر عکس و شناسهٔ رسانهٔ وردپرس را نگه می‌دارد. ابتدا فایل اصلی با کیفیت ۸۰۰ پیکسل و سه اندازهٔ کوچک‌تر ساخته و اعتبارسنجی می‌شود. سپس نگاره‌های شاخص، گالری و تصویرهای گزینه‌های کالا از همان شناسه‌ها، نسخهٔ شفاف را دریافت می‌کنند. برش‌های دستی و تصویرهای تخت مانند راهنمای اندازه در catalog/cutout-overrides.json ثبت شده‌اند تا نوشته و جزئیات آن‌ها حفظ شود.

~~~powershell
python -m pip install Pillow numpy onnxruntime
curl.exe -fL https://github.com/danielgatis/rembg/releases/download/v0.0.0/u2net.onnx -o runtime/u2net.onnx
python scripts/prepare-cutouts.py --model runtime/u2net.onnx --source runtime/media --output runtime/cutouts
python tests/media-alpha.py runtime/cutouts
wp --path=$wpPath eval-file scripts/apply-cutouts.php runtime/cutouts
wp --path=$wpPath eval-file scripts/apply-cutouts.php runtime/cutouts verify
~~~

مدل [U²-Net](https://github.com/xuebinqin/U-2-Net) روی رایانه اجرا می‌شود. هر خروجی موفق ذخیره می‌شود تا اجرای دوباره از آن استفاده کند. فهرست کامل تصویرها برای به‌روزرسانی کتابخانهٔ رسانه لازم است.

## ورود با موبایل و پیامک سفارش

در حساب کاربری فروشگاه، مشتری با موبایل و رمز عبور وارد می‌شود. شمارهٔ تأییدشده با کد پیامکی، شناسهٔ ورود است. مشتری می‌تواند در همان فرم تأیید، رمز عبور تازه‌ای هم انتخاب کند. در صورت انتقال حساب‌های قدیمی، تطبیق شمارهٔ حساب باید با تأیید مالک آن انجام شود. شمارهٔ صورتحساب به‌تنهایی مالکیت یک حساب قدیمی را ثابت نمی‌کند.

مقادیر `MV_ONESMS_KEY` و `MV_ONESMS_FROM` را در محیط اجرای PHP یا پیکربندی خصوصی خارج از پوشهٔ عمومی و مخزن تعریف کنید. اگر وردپرس درخواست‌های خارجی را محدود می‌کند، دسترسی HTTPS به `connect.onesms.ir` را در `WP_ACCESSIBLE_HOSTS` مجاز کنید. پیام ثبت، تکمیل و لغو سفارش از شمارهٔ موبایل صورتحساب استفاده می‌کند. نتیجهٔ درخواست در یادداشت خصوصی سفارش ثبت می‌شود و هر رویداد یک‌بار درخواست ارسال می‌سازد.

خطاهای سرویس پیامک از مسیر «ووکامرس ← وضعیت ← گزارش‌ها» با منبع `moalem-sms` قابل بررسی‌اند. گزارش، نوع خطا و وضعیت HTTP سرویس را ثبت می‌کند. انتظار یک‌دقیقه‌ای ارسال دوباره پس از پذیرش پیامک اعمال می‌شود و سقف درخواست برای شماره و نشانی IP برقرار است.

وقتی OneSMS وضعیت HTTP 402 برمی‌گرداند، گزارش `sms_billing` ثبت می‌شود و صفحهٔ ورود گزینهٔ رمز عبور را یادآوری می‌کند. جزئیات پرداخت یا ماندهٔ اعتبار را از پنل OneSMS بررسی کنید.

مدیر وردپرس می‌تواند شمارهٔ دریافت‌کنندهٔ پیامک سفارش‌های جدید را در پیشخوان، از مسیر «ووکامرس ← مدیر فروشگاه» تعیین کند. تغییر شماره برای سفارش‌های بعدی اعمال می‌شود. خالی گذاشتن شماره، پیامک مدیر را غیرفعال می‌کند.

در همین صفحه، «شماره تماس عمومی مدیر» را برای دکمهٔ تماس در منوی شناور وارد کنید. بازدیدکنندگان شمارهٔ ثبت‌شده در این فیلد را می‌بینند. خالی گذاشتن فیلد، دکمهٔ تماس را پنهان می‌کند.

مدیر وردپرس و مدیر ووکامرس می‌توانند پس از ورود، از منوی کاربران یا شناسنامهٔ خود وارد «ورود پیامکی مدیر» شوند. در این صفحه، مدیر با رمز عبور فعلی و کد پیامکی شمارهٔ ورود حساب خودش را تأیید می‌کند. از آن پس، پیوند «ورود مدیر با رمز یک‌بارمصرف» در صفحهٔ ورود وردپرس، مدیر را به پیشخوان می‌برد. شماره‌های تماس عمومی و گیرندهٔ پیامک سفارش، تنظیمات مستقلی هستند.

## انتشار کالا و مقاله در کانال بله

مدیر وردپرس از «ووکامرس ← کانال بله» شناسهٔ کانال و توکن بازو را وارد می‌کند. بازو در بله باید مجوز انتشار در کانال را داشته باشد. دکمهٔ بررسی اتصال، حساب بازو، نوع مقصد و مجوز انتشار را بررسی می‌کند. در نصب محلی، نشانی دامنهٔ عمومی HTTPS برای پیوند خرید لازم است. اگر شناسهٔ کانال نام کاربری باشد یا پیوند عمومی `ble.ir` وارد شود، کانال در منوی شناور شبکه‌های اجتماعی هم نمایش داده می‌شود. [مستندات بازوی بله](https://docs.bale.ai/)

قیمت روز یا بازهٔ قیمت، تصویر شاخص، دسته، عنوان، توضیح کوتاه و پیوند از محتوای خود وردپرس و ووکامرس خوانده می‌شوند. امضا و نوشتهٔ روی دکمه در تنظیمات تعیین می‌شوند. متن تکمیلی اختیاری از بخش «پست کانال بله» در ویرایش کالا یا مقاله وارد می‌شود. پیش‌نمایش با انتخاب یک کالای عمومی یا مقالهٔ منتشرشده باز می‌شود. انتشار خودکار به اولین انتشار عمومی هر محتوا اختصاص دارد. رسید، رد شدن درخواست و پاسخ نامشخص در جدول پیشخوان ثبت می‌شوند.

توکن واردشده در پیشخوان با OpenSSL و کلید مشتق‌شده از کلید وردپرس رمز می‌شود. در میزبانی مدیریت‌شده می‌توان توکن را با `MV_BALE_BOT_TOKEN` در محیط PHP یا پیکربندی خصوصی تعیین کرد. اگر وردپرس درخواست‌های خارجی را محدود می‌کند، `tapi.bale.ai` را به `WP_ACCESSIBLE_HOSTS` اضافه کنید. در هاست، صف `mv-bale` از Action Scheduler ووکامرس استفاده می‌کند. در محیط محلی با کرون غیرفعال، ارسال اولیه پس از ذخیرهٔ همان نوشته اجرا می‌شود. تلاش‌های بعدی را می‌توان از جدول پیشخوان پس از موعد یا با `wp action-scheduler run --group=mv-bale` اجرا کرد. [مستندات صف ووکامرس](https://actionscheduler.org/api/)

آزمون محلی با `php -d extension=gd cli.phar --path=$wpPath eval-file tests/bale.php` فایل تصویر و بدنهٔ درخواست را با سرویس شبیه‌سازی‌شده بررسی می‌کند.

## داده‌های منتقل‌شده

- کاتالوگ عمومی در ۲۲ نوامبر ۲۰۲۶ شامل ۱۱۶ کالا، ۸۲۶ حالت خرید، ۱۹ دسته و ۷۷۷ تصویر است.
- نام، نشانی کالا، شناسهٔ انبار، قیمت تومان، وضعیت موجودی عمومی، دسته‌بندی، توضیحات، تصاویر و گزینه‌های کالا از فروشگاه مبدأ منتقل شده‌اند. اسکریپت سئو دستهٔ کالاهای بدون دسته و دستهٔ «توپ‌های ورزشی» را در نسخهٔ جدید ثبت می‌کند.
- تصویرها با فهرست catalog/media.json از مبدأ دریافت و داخل کتابخانهٔ رسانهٔ وردپرس بارگذاری می‌شوند. فایل‌های JSON شناسهٔ عمومی مبدأ را برای تطبیق مجدد حفظ می‌کنند.
- هفت مقالهٔ عمومی و شش صفحهٔ راهنما و تماس نیز بازسازی شده‌اند. گزینهٔ چاپ نام و شماره، ورودی جداگانه در صفحهٔ کالا دارد و مشخصات چاپ در سبد و سفارش ذخیره می‌شود.
- اطلاعات خصوصی مبدأ شامل تعداد دقیق موجودی، دادهٔ مشتریان، سفارش‌ها، کلید درگاه و پیکربندی واقعی ارسال از طریق کاتالوگ عمومی در دسترس نیست.
- اینماد از کد و فایل تصویر منتشرشدهٔ دامنهٔ اصلی استفاده می‌کند. عنوان کنار آن در محیط محلی دامنهٔ ثبت‌شده را مشخص می‌کند.

## سئو و نسخهٔ عمومی

قالب عنوان و توضیح متای یکتا، نشانی اصلی، تصویر اشتراک‌گذاری و دادهٔ ساختاریافتهٔ ووکامرس را ارائه می‌دهد. دادهٔ ساختاریافتهٔ قیمت از کد ارز ریال استفاده می‌کند و مبلغ فروشگاه با تومان نمایش داده می‌شود. اصلاح دسته‌ها و توضیحات با حفظ نشانی کالا، شناسهٔ انبار، قیمت و گزینه‌های خرید انجام می‌گیرد. سایت محلی برای موتورهای جست‌وجو بسته است. هنگام انتقال به دامنهٔ عمومی، پس از بررسی آدرس‌ها، درگاه و تنظیمات ارسال، نمایه‌سازی را از تنظیمات خواندن وردپرس فعال کنید. [راهنمای عنوان نتیجهٔ گوگل](https://developers.google.com/search/docs/appearance/title-link) · [راهنمای دادهٔ ساختاریافتهٔ محصول](https://developers.google.com/search/docs/appearance/structured-data/product)

## مقاله‌ها و به‌روزرسانی سئو

متن ۱۰۰ راهنمای تألیفی در پوشهٔ catalog/guides و معرفی موضوع‌ها در catalog/guide-topics.json است. هنگام وارد کردن، شناسه‌های محصولات مبدأ به محصولات همین وردپرس تبدیل می‌شوند. هر راهنما تصویر شاخص و پیوندهای مرتبط محلی دارد. هفت مقالهٔ قبلی نیز با حفظ نشانی و متن، از نظر رسانه و پیوند داخلی بازبینی می‌شوند.

عکس‌های تحریریه برای موضوع هر مقاله ساخته شده‌اند و در `catalog/guide-images` به صورت WebP نگهداری می‌شوند. متن جایگزین فارسی هر عکس و نگاشت تصاویر درون مقاله در `catalog/guide-visuals.json` است. واردکننده تصویر شاخص و اندازه‌های مناسب برای موبایل، دسکتاپ و فهرست مقاله‌ها را در کتابخانهٔ رسانهٔ وردپرس ثبت می‌کند.

این فرمان‌ها را پس از وارد کردن کاتالوگ و کتابخانهٔ رسانه اجرا کنید.

~~~powershell
wp --path=$wpPath eval-file scripts/apply-catalog-seo.php
python scripts/fetch-editorial-media.py runtime/editorial
wp --path=$wpPath eval-file scripts/repair-source-editorial.php runtime/editorial
wp --path=$wpPath eval-file scripts/import-guides.php
wp --path=$wpPath eval-file scripts/import-guide-images.php
wp --path=$wpPath eval-file tests/editorial-audit.php runtime/editorial-audit.json
node tests/editorial-http.cjs runtime/editorial-audit.json
~~~

برای ساخت اندازه‌های مختلف WebP، پشتیبانی GD یا Imagick باید در PHP خط فرمان فعال باشد. در نصب محلی XAMPP می‌توان واردکننده را با `php -d extension=gd cli.phar --path=$wpPath eval-file scripts/import-guide-images.php` اجرا کرد.

## آزمون‌ها

~~~powershell
wp --path=$wpPath eval-file tests/catalog-audit.php
wp --path=$wpPath eval-file tests/commerce.php
npm ci
npx playwright install chromium
npm test
~~~

برای مرورگر نصب‌شده روی ویندوز می‌توان MV_CHROME را روی مسیر فایل Chrome قرار داد. آزمون‌های مرورگر فقط به سایت محلی متصل می‌شوند و مسیر صفحهٔ اول، نمایش موبایل، فهرست کالا، جست‌وجو، انتخاب گزینه، کالای ناموجود، سبد، تسویهٔ آزمایشی و سئو را بررسی می‌کنند. خروجی تصویری در test-results یا مسیر مشخص‌شده با MV_QA_OUTPUT ساخته می‌شود.

برای دو سناریوی مرورگری پیامک، فایل WP-CLI یعنی `cli.phar` را کنار پوشهٔ `wordpress` در Runtime بگذارید و `tests/run-onesms-browser.ps1 -Runtime C:\path\to\runtime` را اجرا کنید. این اسکریپت فقط برای وردپرس محلی است و جایگزین موقت سرویس پیامک و داده‌های آزمون را پس از اجرا پاک می‌کند.

فونت وزیرمتن با مجوز OFL در theme/assets/OFL.txt ارائه شده است. سه تصویر شفاف اسلایدر با ImageGen برای این قالب ساخته شده‌اند. انتخاب دستی، مکث و تنظیم کاهش حرکت دستگاه در مرورگر آزموده شده‌اند.
